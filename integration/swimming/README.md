# Natación: equipo ganador y apoyo con taps

Cada integrante del equipo ganador recibe 45 K$. Los demás no reciben monedas. El pozo pendiente de natación se reparte entre los próximos campeones, con monedas enteras; los premios destinados a usuarios sin cuenta vuelven al pozo. Magikarp tiene su propio pozo y reparte su premio de 45 K$ entre los ganadores si hay empate.

Todos los compañeros pueden impulsar al nadador activo. Los taps pendientes se conservan durante el relevo. Cuando terminan tres de las cuatro calles, la restante obtiene automáticamente el cuarto puesto.

Las rondas con participantes de prueba o avance automático no pagan premios. Los pagos se registran en una transacción y reintentar una ronda no duplica monedas. Instalar.ps1 copia los cambios al experimento local de Pokediscord. El servicio de premios utiliza Shipwright/tools/magikarp-arena/rewards.py y la cartera compartida existente.

Todos los entrenadores muestran nombre y foto incluso cuando esperan. La victoria usa tarjetas separadas para cada campeón. El texto de canvas y controles usa la fuente local original de Stadium; regenera primero magikarp-arena/local-assets/stadium.ttf desde tu ROM. La fuente extraída no se distribuye.
